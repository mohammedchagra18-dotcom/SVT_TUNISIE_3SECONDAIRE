🔬 Chapitre 1 — L'information génétique : des caractères aux gènes

Concept clé

Chaque être vivant est un ensemble de caractères héréditaires déterminés par des informations génétiques (gènes) localisées dans l'ADN des chromosomes. L'information génétique est une séquence de bases azotées qui contrôle la synthèse d'une protéine déterminant le phénotype.

🔬 Activité 2 — Phénotype, génotype et allèles

▼
Définitions essentielles

👁️ Phénotype

  • Aspect observable d'un caractère héréditaire
  • Expression d'un génotype
  • Ex : œil rouge / blanc chez drosophile
  • Ex : HbA (normal) / HbS (drépanocytose)

🧬 Génotype

  • Information génétique qui détermine le phénotype
  • Ensemble des gènes (couple d'allèles) d'un individu
  • Localisé dans l'ADN des chromosomes

🔗 Gène et Allèle

  • Gène : séquence de bases ADN → synthèse d'une protéine
  • Locus : emplacement précis du gène sur le chromosome
  • Allèle : forme particulière d'un gène
  • Couple d'allèles : 2 allèles sur chromosomes homologues

⚖️ Homo / Hétérozygote

  • Homozygote : les 2 allèles identiques (A//A)
  • Hétérozygote : les 2 allèles différents (A//S)
  • Chez les diploïdes : 2 chromosomes homologues → 2 allèles

⚗️ Chapitre 2 — Mécanisme de l'expression génétique

Principe fondamental

Chaque phénotype résulte de l'expression d'un génotype via la synthèse d'une protéine. Cette synthèse se fait en deux étapes : transcription (ADN → ARNm dans le noyau) et traduction (ARNm → protéine dans le cytoplasme).

🔬 Activité 3 — La traduction : ARNm → protéine

▼
A — Les acteurs de la traduction

🔩 Ribosome

  • Organite cytoplasmique
  • Grande + petite sous-unités
  • Composé de protéines (20%) et ARNr (80%)
  • Site de la synthèse protéique
  • Cellules actives (ex: cellules pancréatiques) = ribosomes +++

🚛 ARN de transfert (ARNt)

  • Molécule de 75 nucléotides
  • Chaque ARNt est spécifique d'un acide aminé
  • Porte un anticodon (triplet complémentaire du codon)
  • 20 types d'ARNt (1 par acide aminé)

⚡ Énergie et enzymes

  • ATP indispensable
  • Enzymes (ATPases, peptidases)
  • Ions Mg²⁺, PO₄³⁻
B — Le code génétique
Codon : triplet de 3 bases consécutives de l'ARNm qui détermine le positionnement d'un acide aminé dans un polypeptide.
Codon d'initiation : AUG → méthionine (Met) — début de la traduction.
Codons stop : UAA, UAG, UGA → arrêt de la traduction (ne codent pour aucun AA).
Code universel : identique pour tous les êtres vivants. Code dégénéré : plusieurs codons pour un même acide aminé.
Nécessité d'un triplet : avec 4 bases et 20 acides aminés → 1 base : 4¹=4 combinaisons (insuffisant) · 2 bases : 4²=16 (insuffisant) · 3 bases : 4³=64 combinaisons (>20 acides aminés ✓)
